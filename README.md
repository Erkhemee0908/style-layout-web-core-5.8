# CPS Services and Support Page

Web Core, Lesson 5.8

Responsive layout of a service centre landing page, built with HTML and CSS.

## Features

- Mobile first responsive layout for 320px, tablet (784px) and desktop (1120px)
- Flexbox for all layout
- BEM naming with the `block__elem--mod` convention
- Horizontally scrolling tab menu on mobile with a hidden scrollbar
- Text and hero image split the screen evenly on tablet and desktop
- Accessible tab markup with ARIA roles

## Built with

- HTML
- CSS
